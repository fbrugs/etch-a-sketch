# Etch-a-Sketch

A simple browser-based Etch-a-Sketch built with HTML, CSS, and vanilla JavaScript.

The project allows you to create a customizable drawing grid and draw by hovering over individual cells. It includes random RGB colors and an opacity/darkening mode.

Features:

-Draw by hovering over the grid
-Create a customizable grid
-Grid sizes from 10 × 10 to 80 × 80
-RGB mode with randomly generated colors
-Opacity mode for gradually darkening cells
-Standard black drawing mode
-Change the grid size at any time
-RGB and opacity modes cannot be enabled simultaneously
